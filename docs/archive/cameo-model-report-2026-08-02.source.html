3. Summary

  • Blocks: 32 architecture Blocks + 2 ConstraintBlocks modeled across 6 subsystems and the top-level system, consistent with the academic/architecture-level scope (no RF link budgets, frequencies, protocols, gain patterns, transmit power, or firmware/hardware part numbers resolved).
  • Open trade studies: concentrated in material selection (Airframe), COTS component sizing (Propulsion, Power), firmware/camera class (Avionics), RF implementation and regulatory compliance (Communications — by design, since this is explicitly out of scope for the architecture pass), and one unresolved scope decision (AVN-GNSS / position-hold capability).
